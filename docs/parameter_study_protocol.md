# Frozen structural parameter study

Separate authored campaign:23 inputs, eight declared families, six exact methods,
two forward/reverse repetitions =276 scheduled observations. Same five DP
ablations and strengthened CP-SAT;30s external pipeline deadline,25s internal CP
budget,100000 raw states,65536 cut columns, solver seed0, no enforced RAM cap.
No heuristic or building-derived results are pooled into this campaign. Inputs
passed recognizer preflight; this is input validation, not timed solver evidence.
No other solver campaign or regression suite runs concurrently during measurement.

| Family | Levels | Fixed | Varied / coupled changes | Interpretation |
|---|---|---|---|---|

Every input stores these declarations, IDs and a fingerprint. Generated instance
numbers are structural family levels, not independent buildings or price draws.
Both repetition observations remain in the final record, including limits/errors.
The complete schedule is written before the first worker starts. Primary timing
includes fresh worker startup, recognition/model construction and required replay.
All profile instrumentation is the same as the building campaign; do not compare
absolute times across these different input populations as a single experiment.

orders; it is a null schedule-sensitivity result, not evidence of varied width.

They have the same six-floor geometry, one complete owner unit/eight actions,
edge costs and source/target. Paired edge events retire each intermediate vertex
before introducing the next; batched events retain all four. A focused check

bound. Original null-control inputs/observations remain preserved.
