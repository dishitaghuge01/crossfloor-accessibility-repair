## What is still needed for a stronger submission

1. **Complete multi-room source extraction.** Preserve an auditable floor-wide
   nonoverlapping space subset, extract doors only with explicit source evidence
   and source geometry, map existing vertical facilities and all intervening
   floor footprints, and retain unsupported objects as exclusions. Never infer
   traversal from shared boundaries alone. Admission must verify original
   profile routes before an original-portal corruption is called restoration.
2. **Nontrivial topology evidence.** Evaluate multiple required rooms per floor,
   with a nonempty shared-boundary graph and competing portal locations. Freeze
   coordinates and GlobalIds, check every adjacency edge after full replay,
   and report extraction exclusions and retained/omitted room counts.
3. **Measure the useful structural regime.** Report p, full and marked r, z,
   complete unit spans L, h and recognition cost on every source. Include cases
   with many actions but bounded interfaces and cases violating each bound.
   Compare CP-SAT and both DP modes under identical budgets and input hashes;
   separate recognition/optimization/replay by direct instrumentation if used.
4. **Finish the theorem/closest-equivalence gate.** Obtain independent proof
   review of witness completion, ownership forgetting and product-profile
   representation. Audit whether a tighter generic domain-valued resource DP
   matches the proposed dependence. A standard hardness transfer supplies a
   boundary, not a newness certificate. Record either equivalence or a precise
   structural separation without replacing a missing runtime result with a
   constructed upper bound.
5. **Choose a venue and prepare its version.** The current thirteen-page IEEE
   master includes proof appendices and nine figures. Supply actual authors and
   venue rules, move permitted appendices to a supplement, and validate its
   actual PDF/page requirements. Formatting cannot settle G3 or remove the
   public-extraction gap.

These are concrete research deliverables. The current PR can be reviewed as an
evidence-backed improvement, while the remaining breadth and priority work
stays explicit.
