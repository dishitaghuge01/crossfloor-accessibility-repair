## Claim-by-claim disposition

1. **Supported project deliverable:** the specified physical-to-owned-interface construction, complete paid-effects semantics, original cost/count/ID transfer, recognized scope, implementation and reproducible evaluation.
2. **Argument supplied, independent review pending:** correctness of the specialized construction and its stated interface bound. Automated agreement and counterexamples support implementation behavior; they do not independently establish a theorem's priority.
3. **Not claimed:** first use of layering, conflicts, profiles, shared purchase costs, representative bases or bounded-width exact connectivity.
4. **Unresolved comparison risk:** a generic finite-domain connectivity/CSP treatment may reproduce the ownership-domain factor once given an appropriate decomposition. No lower bound rules out a tighter generic encoding. For fixed owner multiplicity, the current displayed generic and specialized exponent bounds already have the same asymptotic interface dependence.
5. **Priority gate:** OPEN. A sentence saying no prior work can express this model would be unjustified. The absence of an equivalent construction in this bounded inspection is not a proof of absence.

Recommended wording remains: We give an explicit semantics-preserving transfer from a recognized physical action catalogue to an owned-cell floor interface, retaining complete paid effects and original-action optimization, and evaluate the resulting exact algorithm. This wording specifies what was built without claiming first-in-literature status.

## What would change the decision

A prior paper with a matching semantic construction and comparable parameter dependence would require narrowing the algorithmic claim. Conversely a source-by-source checked distinction can strengthen the evidence for a specialized contribution but cannot provide an absolute nonexistence certificate. The partially accessible choice-network and September routing proofs remain explicit inspection limits. No author contact, submission or push occurred.
